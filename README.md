# FIZEMOS$ — site

## Como colocar no GitHub

1. Envie `index.html` e a pasta `assets` para a raiz do seu repositório.
2. Dentro de `assets`, mantenha:
   - `logo.jpg`
   - `lobby.png`
3. No final do `index.html`, procure por:
   `const WHATSAPP_NUMBER = "SEUNUMERO";`
4. Troque por seu número, por exemplo:
   `const WHATSAPP_NUMBER = "5511999999999";`
5. Se estiver usando GitHub Pages, ative Pages em Settings > Pages e selecione a branch principal.

O projeto é HTML/CSS/JS puro: não precisa instalar React, Node ou qualquer dependência.
